Users can request manga once the Manga category is on and a Suwayomi server is connected, choosing all chapters, the latest chapters or a chapter range. Approved requests show Waiting for a source until the title has a library match. Administrators can grant Request Manga and Auto-Approve Manga and set manga request limits. Requests are not sent to Suwayomi yet.
