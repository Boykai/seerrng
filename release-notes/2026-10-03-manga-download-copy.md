Manga requests offer each verified chapter as a Download copy on their Request Status card, while the rest is still downloading, after a failure and once available. Each chapter downloads as a CBZ file passed through from Suwayomi, and SeerrNG stores nothing. Each user can run 2 chapter downloads at a time and each Suwayomi server 4.
