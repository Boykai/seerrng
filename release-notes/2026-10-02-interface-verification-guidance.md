Interface guidance now separates focused edit checks from the final cumulative gate, preserves Request-page and shared-role work alongside Series changes, and supplies a maintainer integration evidence checklist. Unrelated backend failures require explicit scope review rather than automatic repair.

The procedure also checks complete repository fixtures and native tool prerequisites before an expensive cumulative run. A runtime app snapshot or Linux platform alone is not sufficient verification input.
