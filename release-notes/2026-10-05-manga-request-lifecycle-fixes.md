Manga request history now records each status message change. A title shows as in the library once a request adds it, Follow New Chapters applies when a request approves a pending one, reopened requests are noted in Suwayomi again, and long requests list each newly verified chapter. Cancelled source runs stop, and an administrator's source search that a run defers waits for its next check.
