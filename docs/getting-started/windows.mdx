# Install SeerrNG on Windows

The Chocolatey package installs SeerrNG as a Windows service. It installs the
Node.js 24 runtime and NSSM service manager as package dependencies.

The initial package must be approved by the Chocolatey Community Repository
before it appears in the public feed. After it is available, install SeerrNG
from an elevated PowerShell or Command Prompt:

```powershell
choco install seerrng -y
```

Open [http://localhost:5055](http://localhost:5055) to finish the first-run
setup. To check or restart the Windows service:

```powershell
Get-Service SeerrNG
Restart-Service SeerrNG
```

Upgrade with Chocolatey:

```powershell
choco upgrade seerrng -y
```

Package upgrades update the existing `SeerrNG` service. Application settings,
the database, and logs remain under `%ProgramData%\SeerrNG\config`; removing
the package removes the service and application files while preserving that
configuration directory.
